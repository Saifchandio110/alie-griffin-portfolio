# Character artwork slots

Drop transparent-background images here and the site uses them automatically.
If a file is missing, the built-in drawn character is shown instead.

| File name (WebP preferred, PNG also works) | Where it appears | Suggested size |
| --- | --- | --- |
| welcome-girl.webp | Welcome screen (large, waving) | about 800 px tall |
| edge-girl-1.webp | Small walker, bottom edge (home and About) | about 300 px tall |
| edge-girl-2.webp | Second small walker, bottom edge | about 300 px tall |
| edge-girl-3.webp | Floating character, right edge (large screens only) | about 300 px tall |

Tips:
- Transparent background (WebP or PNG), under about 300 KB each.
- Use original art you have the rights to. Do not use existing copyrighted characters.
